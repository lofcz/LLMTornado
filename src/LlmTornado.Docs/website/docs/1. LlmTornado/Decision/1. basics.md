# Decision

## Overview

The decision endpoint evaluates a piece of *state* (text or structured data) against a set of typed questions and returns structured answers with calibrated probabilities instead of generated text. Use it for classification, intent routing, scoring, extraction checks and guardrails. There is nothing to parse: each answer is a probability, a chosen option, or a position on a scale, together with a confidence your code can threshold on.

LlmTornado provides this through [TypeSafe](https://docs.typesafe.ai) and its System One model **Jev**. All questions in a request are evaluated in parallel against the same state, so ask several at once.

## Quick Start

```csharp
using LlmTornado;
using LlmTornado.Decision;
using LlmTornado.Decision.Models;
using LlmTornado.Code;

TornadoApi api = new TornadoApi([
    new ProviderAuthentication(LLmProviders.TypeSafe, "your-typesafe-api-key")
]);

DecisionRequest request = new DecisionRequest(DecisionModel.TypeSafe.Jev.Latest,
        "Help! My payouts have been failing for 3 days.")
    .AddNoul("is_urgent", "Does this convey urgency?")
    .AddChoice("department", "Which team should handle this?", new Dictionary<string, object?>
    {
        ["billing"] = "Payments, invoicing, refunds",
        ["technical"] = "Bugs, outages, integrations",
        ["sales"] = "Pricing, upgrades, new accounts"
    })
    .AddScore("frustration", "How frustrated is the customer?", "Calm", "Frustrated", "Very angry");

DecisionResult? result = await api.Decision.CreateDecision(request);

Console.WriteLine(result.GetNoul("is_urgent")?.Noul);            // 0.95
Console.WriteLine(result.GetChoice("department")?.Choice);       // billing
Console.WriteLine(result.GetScore("frustration")?.Score);        // 1.05
```

## Prerequisites

- The LlmTornado package installed
- A TypeSafe API key from [console.typesafe.ai/keys](https://console.typesafe.ai/keys)

## Question Types

| Type | Class | Asks | Answer |
|:---|:---|:---|:---|
| Noul | `DecisionNoul` | A yes/no question | `Noul`: probability of yes, 0 to 1 |
| Choice | `DecisionChoice` | Pick one option from a set (max 255) | `Choice`, `Probabilities` per option, `Confidence` |
| Score | `DecisionScore` | Rate against 2 to 10 ordered levels | `Score` (0 to levels - 1), `Legend`, `Probabilities` per level, `Confidence` |

Keep each question atomic. Break a complex judgment into several small questions and combine the answers in code.

### Noul

```csharp
request.AddNoul("wants_human", "Is the customer asking for a human agent?");

// optionally describe what yes and no mean
request.AddNoul("is_repeat_contact", "Has the customer contacted support about this before?",
    @true: "Mentions a prior attempt, ticket, or that they have asked before",
    @false: "No sign of any previous contact");
```

A value near 1 is a strong yes, near 0 a strong no, and around 0.5 is uncertain. Noul answers carry no separate confidence.

### Choice

Each option maps to a description. Use `null` when an option needs no extra detail, and consider adding an "other" option so the model has somewhere to put inputs that fit nothing else.

```csharp
request.AddChoice("action", "What is the user trying to do?", new Dictionary<string, object?>
{
    ["upgrade"] = "Move to a higher tier",
    ["cancel"] = "End the subscription",
    ["other"] = null
});

// or bare option names
request.AddChoice("language", "Which language is the text written in?", "en", "de", "cs", "other");
```

Descriptions can be structured to sharpen boundaries between options:

```csharp
["billing"] = new
{
    what = "Charges, invoices, refunds, or subscriptions",
    not_for = "Order tracking or account access",
    examples = new[] { "I was charged twice", "Where is my refund?" }
}
```

### Score

Levels are ordered, lowest first. The score is the probability-weighted position and can land between levels.

```csharp
request.AddScore("bug_severity", "How severe is the reported issue?",
    "Cosmetic; no impact to functionality",
    "Broken or degraded feature, but workaround exists",
    "Blocking issue; no workaround exists");

DecisionScoreAnswer? severity = result.GetScore("bug_severity");
Console.WriteLine($"{severity.Score:F2} ({severity.Legend[severity.Probabilities.MaxBy(p => p.Value).Key]})");
```

## Structured State and Instructions

`State` and `Instructions` accept any object, not only strings. Put the question in one field and the data it refers to in others, then reference fields by name in backticks:

```csharp
var state = new
{
    source_text = "Invoice #4471 issued March 3, 2026 to Beaver Dam Logistics for $12,840.00, net 30."
};

DecisionRequest request = new DecisionRequest(DecisionModel.TypeSafe.Jev.Latest, state)
    .AddNoul("invoice_number_is_correct", new
    {
        extracted_value = "4471",
        question = "Does `extracted_value` match the invoice number in `source_text`?"
    });
```

## Confidence-Gated Routing

`Confidence` (0 to 1) is derived from how concentrated the probability distribution is. Use it to decide whether to act automatically:

```csharp
DecisionChoiceAnswer? action = result.GetChoice("action");

if (action.Confidence >= 0.8)
{
    Route(action.Choice);
}
else
{
    EscalateToHuman(bestGuess: action.Choice);
}
```

The full `Probabilities` map is always returned, so you can compute your own statistics.

## Models

| Model | Name | Notes |
|:---|:---|:---|
| `DecisionModel.TypeSafe.Jev.Latest` | `jev-latest` | Most recent stable release. Moves when a new version ships. |
| `DecisionModel.TypeSafe.Jev.Preview` | `jev-preview` | Most recent release, including previews. |
| `DecisionModel.TypeSafe.Jev.V1_13` | `jev-1.13.0` | Pinned version. Prefer pinning when confidence thresholds were tuned against a version. |

Any string is accepted too: `DecisionModel model = "jev-1.14.0";` resolves to the TypeSafe provider. The response's `Model` property reports the versioned id that answered.

Limits (Jev 1.13): text input only, 64k tokens per request, 32k tokens for state plus the longest question.

## Error Handling

`CreateDecision` throws on failure. Use `CreateDecisionSafe` to get an `HttpCallResult<DecisionResult>` instead:

```csharp
HttpCallResult<DecisionResult> result = await api.Decision.CreateDecisionSafe(request);

if (!result.Ok)
{
    Console.WriteLine($"{result.Code}: {result.Response}");
}
```

Rate-limited (`429`) and overloaded (`529`) responses should be retried with exponential backoff.

## API Reference

### DecisionRequest
- `DecisionModel Model` - Model to use
- `object State` - Text or structured data to evaluate
- `Dictionary<string, DecisionQuestion> Questions` - Questions keyed by an id you choose
- `AddNoul` / `AddChoice` / `AddScore` - Fluent helpers

### DecisionResult
- `string Model` - Versioned model id that answered
- `Dictionary<string, DecisionAnswer> Answers` - One answer per question id
- `DecisionUsage Usage` - `InputTokens`, `OutputTokens`
- `GetNoul` / `GetChoice` / `GetScore` - Typed accessors; return null on unknown id or type mismatch

### Answers
- `DecisionNoulAnswer` - `double Noul`
- `DecisionChoiceAnswer` - `string Choice`, `Dictionary<string, double> Probabilities`, `double Confidence`
- `DecisionScoreAnswer` - `double Score`, `Dictionary<string, object> Legend`, `Dictionary<string, double> Probabilities`, `double Confidence`

## OpenRouter Decisions

OpenRouter uses the alpha endpoint `https://openrouter.ai/api/alpha/decisions`.
Select models through `DecisionModel.OpenRouter.All`. Other OpenRouter endpoints continue to use `v1`.
See the [OpenRouter Decisions reference](https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request).

```csharp
using LlmTornado;
using LlmTornado.Code;
using LlmTornado.Common;
using LlmTornado.Decision;
using LlmTornado.Decision.Models;
using LlmTornado.Decision.Vendors.OpenRouter;

TornadoApi api = new TornadoApi(LLmProviders.OpenRouter, "your-openrouter-api-key");
DecisionRequest request = new DecisionRequest(DecisionModel.OpenRouter.All.Jev113, "The checkout page is blank.")
    .AddNoul("is_bug", "Does this report a software defect?");
request.VendorExtensions = new DecisionRequestVendorExtensions(new DecisionRequestVendorOpenRouterExtensions
{
    Provider = new DecisionOpenRouterProviderPreferences { Zdr = true, AllowFallbacks = false },
    SessionId = "ticket-1"
});
HttpCallResult<DecisionResult> result = await api.Decision.CreateDecisionSafe(request);
```

The example uses Jev. Select `DecisionModel.OpenRouter.All.Gpt6LunaDecisions` for Luna Decisions.
`State` also accepts JSON objects and arrays, including multimodal content supported by the selected model.
Routing preferences, `User`, `SessionId` and `Trace` belong in `DecisionRequestVendorOpenRouterExtensions`.
Results include the generation `Id`, the actual `Model`, the `UpstreamProvider` and `Usage.Cost` in USD.

OpenRouter can omit `Probabilities` and `Legend`; their dictionaries are empty when omitted.
`Confidence` defaults to zero when omitted. This default does not indicate reported model confidence.
Score legends preserve string, object and array descriptions.

For OpenRouter noul questions, omit criteria or provide both `true` and `false` descriptions.
Incomplete criteria cause an `ArgumentException` during serialization.
`CreateDecisionSafe` returns a local `BadRequest` result with this exception before sending a request.

The registry contains 13 alpha Decisions entries, including the Jev latest alias, as of October 7, 2026.
The catalog's Decisions label does not guarantee alpha endpoint compatibility.
Tev1 uses Chat Completions and is not registered as an alpha Decisions model.

`api.Models.GetModels(LLmProviders.OpenRouter)` requests all output modalities.
`Architecture.InputModalities`, `Architecture.OutputModalities` and `SupportedParameters` are lists.
Filter Decision models with `model.Architecture?.OutputModalities?.Contains("decisions") == true`.
This also includes models that support both text and decisions.

### Zero Data Retention

As of October 7, 2026, `openai/gpt-6-luna-decisions` has no ZDR-compatible route on OpenRouter.
Requests with `provider.zdr: true` fail for this model.
If your application requires ZDR, keep it enabled. Do not retry automatically without ZDR.
Account-level restrictions also apply. The SDK passes the requested policy unchanged and returns the server error without relaxing ZDR.
See the [ZDR-filtered model catalog](https://openrouter.ai/api/v1/models?output_modalities=decisions&zdr=true) and [OpenRouter ZDR documentation](https://openrouter.ai/docs/guides/features/zdr).

### Live Tests

`OpenRouterDecisionLiveTests` checks all three answer types and the model catalog through real API calls.
The tests require explicit selection and `OPENROUTER_API_KEY`, or an `OpenRouter` entry in the Demo `apiKey.json`.
Without a key, they are skipped. Production API calls can incur charges.

Run from the repository root in PowerShell:

```powershell
$env:OPENROUTER_API_KEY = 'your-openrouter-api-key'
$testArgs = @('test', 'src/LlmTornado.Tests/LlmTornado.Tests.csproj', '--filter', 'FullyQualifiedName~OpenRouterDecisionLiveTests', '-p:GeneratePackageOnBuild=false', '-p:SkipViteBuild=true')
dotnet @testArgs
```

The default models are `openai/gpt-6-luna-decisions` and `typesafe/jev-1.13`.
Each model has a separate Decision test case. A failure for one model does not prevent testing the other.
The catalog test checks both models in one request.
Set `OPENROUTER_DECISION_MODEL` to one alpha Decisions model to test only that model.
The tests preserve account privacy settings. Luna requests fail if the account requires ZDR for OpenAI.
